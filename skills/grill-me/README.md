# Grill Me

A shortcut for [Grilling](../grilling/README.md).

```text
Use grill-me to challenge this idea before we build it.
```

The agent switches to Grilling and asks structured questions to uncover missing decisions and assumptions. Both skills must be available.

*Based on [Matt Pocock's skills](https://github.com/mattpocock/skills). The original MIT license is preserved.*
